ברוכים הבאים ליחידה 2: ווֹרדל בעברית!

🎯 מטרה: לבנות לבד, שלב אחר שלב, משחק ניחוש מילים שלם באנדרואיד – וללמוד תוך כדי מה זה Activity, איך בונים מסך, איך מגיבים ללחיצות ואיך לא מאבדים את המשחק כשהטלפון מסתובב.

ווֹרדל הוא משחק פשוט להסבר וקשה להפסקה: צריך לנחש מילה בת 5 אותיות ב-6 ניסיונות. אחרי כל ניחוש האותיות נצבעות – ירוק לאות שנמצאת במקום הנכון, צהוב לאות שקיימת במילה אבל במקום אחר, ואפור לאות שלא במילה בכלל.

מה תלמדו (לפי תוכנית הלימודים)

  • מבוא לאפליקציה – מה זה Activity, איך בנוי פרויקט, ומעגל החיים של המסך (שלבים 1–2).
  • ממשק משתמש – לבנות מסך ב-XML עם LinearLayout, ליצור רכיבים מקוד, ולשמור את המשחק בסיבוב המסך (שלבים 3, 4, 10).
  • משאבי האפליקציה – טקסטים, צבעים, מידות וצורות בתיקייה res (לאורך כל הדרך, כל משאב כשצריך אותו).
  • טיפול באירועים – ארבע דרכים להגיב ללחיצה, כל אחת על כפתור אחר במשחק (שלבים 5, 6, 8, 9).

מה זה Activity?

Activity (פעילות) היא מסך אחד באפליקציה. למשחק שלנו יש מסך אחד, ולכן Activity אחת: MainActivity. כל מסך בנוי משני קבצים: קובץ Java שמחליט מה המסך עושה, וקובץ XML שמתאר איך המסך נראה.

Minimum SDK

הגרסה הישנה ביותר של אנדרואיד שהאפליקציה תסכים לרוץ עליה. נבחר API 24 (אנדרואיד 7) – כמעט כל הטלפונים היום.

📘 חלק א – מה צריך לדעת

מי מפעיל את המסך?

בתוכנית Java מיחידה 1 הייתה main, והתוכנית רצה ממנה מההתחלה עד הסוף. ב-MainActivity אין main. מי שמפעיל אותה הוא אנדרואיד: בכל פעם שמשהו קורה למסך – הוא נפתח, הוא מוסתר, הוא נסגר – אנדרואיד קורא לאחת המתודות שלה. רצף המצבים האלה נקרא מעגל החיים של הפעילות:

  • onCreate – הפעילות נוצרת. כאן בונים את המסך. נקראת פעם אחת לכל פעילות.
  • onStart / onStop – המסך מוצג / כבר לא מוצג.
  • onResume / onPause – אפשר ללחוץ על המסך / כבר אי אפשר.
  • onDestroy – הפעילות נהרסת, וכל מה שהיה בה נמחק.

איך כותבים מתודה שאנדרואיד קורא לה: @Override ו-super

MainActivity יורשת (extends) מ-AppCompatActivity – מחלקה של אנדרואיד שכבר יש בה את כל המתודות האלה. כמו ביחידה 1, כדי לשנות מתודה שירשנו כותבים אותה מחדש עם @Override. בשורה הראשונה קוראים ל-super, כדי שהחלק של אנדרואיד ירוץ קודם. בלי super האפליקציה קורסת.

מה זה Log?

Log הוא הודעה שהאפליקציה כותבת למפתח – לכם. המשתמש לא רואה אותה. זה כמו System.out.println מיחידה 1, רק שההודעות מופיעות בחלון מיוחד באנדרואיד סטודיו שנקרא Logcat.

כותבים Log.d(TAG, "הודעה"). d הוא קיצור של debug – הודעה לצורך פיתוח. TAG הוא תווית: מילה קבועה שמופיעה ליד כל הודעה שלנו. בחלון Logcat יש המון הודעות של אנדרואיד עצמו, ולפי התווית מסננים רק את שלנו.

import: כדי להשתמש ב-Log צריך שורת import android.util.Log; בראש הקובץ. אם Log נצבע באדום – עמדו עליו ולחצו Alt+Enter, ואנדרואיד סטודיו יוסיף את השורה בשבילכם.

שלב 3: הכותרת וההודעה

🎯 בסוף השלב: המסך הראשון של המשחק – כותרת ירוקה ושורת הודעה על רקע אפור-בהיר.
📘 חלק א – מה צריך לדעת

תבנית XML

הקובץ activity_main.xml מתאר מה יש על המסך. כל תגית בו (למשל <TextView>) היא רכיב על המסך, והמאפיינים שלה (android:text, android:textSize...) קובעים איך הוא נראה. רכיב על המסך נקרא View. TextView הוא View שמציג טקסט.

LinearLayout: אחד מתחת לשני

המסך של המשחק הוא רשימה של אזורים: כותרת, הודעה, לוח, מקלדת. LinearLayout הוא View שמחזיק בתוכו Views אחרים ומסדר אותם בשורה. עם orientation="vertical" – מלמעלה למטה, בסדר שבו כתבנו אותם. בשלב הזה נשים בו שני רכיבים, ובשלבים הבאים נוסיף עוד.

רוחב וגובה

לכל View חייבים לתת רוחב (layout_width) וגובה (layout_height). שני הערכים הנפוצים:

gravity="center" ממרכז את הטקסט בתוך הרכיב.

שם לרכיב: id

android:id="@+id/txtTitle" נותן לרכיב שם, כדי שקוד ה-Java יוכל למצוא אותו. ה-+ אומר "צור את השם הזה". זוכרים את R.id.main מהשלב הראשון? הקוד של אנדרואיד סטודיו מחפש רכיב בשם main, ולכן ל-LinearLayout שלנו חייבים לקרוא בשם הזה.

יחידות מידה: dp ו-sp

לטלפונים שונים יש מספר שונה של נקודות (פיקסלים) על אותו גודל מסך. לכן לא מודדים בפיקסלים אלא ב-dp: יחידה שנראית באותו גודל בכל טלפון. לגודל טקסט משתמשים ב-sp – כמו dp, אבל גדל אם המשתמש הגדיל את הגופן בהגדרות.

משאבים: שמות במקום ערכים

בתבנית לא נכתוב את הטקסט עצמו ואת הצבע עצמו, אלא שם: @string/title, @color/primary. הערכים יושבים בתיקייה res/values, כל סוג בקובץ משלו – strings.xml, colors.xml, dimens.xml. הם נקראים משאבים. היתרון: הירוק של המשחק נכתב פעם אחת, וכל רכיב שצריך אותו משתמש בשם. רוצים גוון אחר? משנים במקום אחד.

R: בכל בנייה אנדרואיד סורק את res ויוצר מחלקה בשם R, עם קבוע לכל משאב ולכל id: R.string.title, R.id.main. כך קוד ה-Java מגיע אליהם. טעות כתיב בשם – והפרויקט לא מתקמפל.

ערכת נושא (Theme)

הקובץ themes.xml קובע את העיצוב של כל האפליקציה: הצבע הראשי, צבע הרקע. נשנה בו את הצבע הראשי לירוק שלנו ואת הרקע לאפור-בהיר. יש גם קובץ values-night/themes.xml – העיצוב למצב לילה. המשחק שלנו תמיד בהיר, אז נמחק אותו.

📘 חלק א – מה צריך לדעת

למה לבנות את הלוח בקוד?

30 אריחים זהים ב-XML הם 30 תגיות זהות. ב-Java זו לולאה אחת, והאריחים נשמרים במערך דו-ממדי tiles[שורה][עמודה] – בדיוק מה שהמשחק צריך: "האריח בשורה 2, עמודה 0". כלל אצבע: רכיב ייחודי – ב-XML. רכיבים שחוזרים על עצמם – בקוד. ב-XML נשים רק מיכל ריק – LinearLayout בשם boardContainer – והקוד ימלא אותו.

layout_weight: כל הגובה שנשאר

הכותרת וההודעה לוקחות כמה שהן צריכות (wrap_content). את הלוח נרצה בכל השאר. לשם כך נותנים לו layout_height="0dp" ו-layout_weight="1": "גובה – לפי משקל; קח את כל המקום הפנוי".

מימין לשמאל: layoutDirection

LinearLayout אופקי מסדר את הרכיבים לפי כיוון השפה של הטלפון. בטלפון שמוגדר לאנגלית – משמאל לימין, ואז מילה עברית בלוח נקראת הפוך. android:layoutDirection="rtl" (right-to-left) מכריח ימין-לשמאל: עמודה 0 תמיד בצד ימין.

צורה ב-XML: drawable

הרקע של אריח הוא לא תמונה אלא צורה שמתוארת ב-XML: מלבן, צבע מילוי, מסגרת ופינות מעוגלות. קבצים כאלה יושבים בתיקייה res/drawable, ובקוד מגיעים אליהם דרך R.drawable.שם.

ליצור View בקוד

עד עכשיו כל רכיב נוצר מ-XML. אפשר ליצור רכיב גם ב-Java, כמו כל אובייקט: new TextView(this). this הוא הפעילות – כל View צריך לדעת לאיזה מסך הוא שייך. את הגודל והשוליים של רכיב שנוצר בקוד שמים באובייקט LayoutParams, ובסוף addView מכניס אותו לתוך ההורה. בלי addView הרכיב קיים בזיכרון, אבל לא מופיע על המסך.

הגודל ב-dimens.xml כתוב ב-dp, אבל בקוד צריך פיקסלים. getResources().getDimensionPixelSize(R.dimen.tile_size) ממיר בשבילנו, לפי הטלפון.

boardContainer הוא LinearLayout אנכי. נכניס לתוכו 6 שורות, וכל שורה היא LinearLayout אופקי עם 5 אריחים. כל אריח נשמר גם במערך tiles, כדי שאפשר יהיה לכתוב לתוכו אחר כך. כדי להגיע מהקוד אל boardContainer שב-XML משתמשים ב-findViewById(R.id.boardContainer) – הוא מחפש את הרכיב לפי ה-id ומחזיר אותו.

לכל 27 המקשים צריך אותו גודל, אותו צבע ואותו onClick. במקום לכתוב את זה 27 פעמים, כותבים סגנון – חבילת מאפיינים עם שם – ב-themes.xml, ונותנים אותו לכל מקש בשורה אחת: style="@style/KeyButton". בסגנון יש layout_width="0dp" ו-layout_weight="1" – אותו רעיון כמו בלוח, רק לרוחב: כל המקשים בשורה מתחלקים ברוחב שווה.

קובץ נפרד למקלדת: include

המקלדת ארוכה, אז נשים אותה בקובץ משלה, keyboard.xml. התגית <include> מכניסה את הקובץ הזה לתוך המסך הראשי, כאילו היה כתוב שם.

איזה מקש נלחץ? המרה ל-Button

המתודה מקבלת View view – הטיפוס הכללי. אנחנו יודעים שזה כפתור, אז ממירים אותו ל-Button (casting, כמו ביחידה 1) וקוראים את הטקסט שלו. הטקסט של הכפתור הוא האות – לכן לא צריך 27 מתודות.

📘 חלק א – מה צריך לדעת

למה "מחק" צריך מאזין אחר?

אם "מחק" ישתמש בסגנון של האותיות, הלחיצה תגיע ל-onLetterKey, והיא תכתוב בלוח את האות "מ". לכן נכתוב לו android:onClick="@null" – "בלי onClick מהסגנון" – ונחבר לו מאזין אחר.

setOnClickListener והממשק OnClickListener

הדרך הכללית לחבר מאזין היא מהקוד: button.setOnClickListener(מאזין). המאזין הוא אובייקט שיש לו מתודה onClick(View view). הדרישה הזאת מוגדרת בממשק (interface) בשם View.OnClickListener – כמו הממשקים מיחידה 1: מחלקה שמממשת (implements) אותו, מתחייבת שיש לה onClick.

דרך 2: הפעילות עצמה היא המאזין

במקום ליצור אובייקט חדש, הפעילות עצמה מממשת את הממשק, ומעבירים אותה עם this. היתרון על דרך 1: אם שכחתם לכתוב onClick, המהדר יגיד לכם מיד – עוד לפני שהרצתם.

מי נלחץ? getId

כמה כפתורים יכולים להשתמש באותה פעילות כמאזין, ואז כולם מגיעים לאותה onClick. view.getId() מחזיר את ה-id של הכפתור שנלחץ, ומשווים אותו ל-R.id.btnDelete.

/**
 * מצב של אות אחת בניחוש. כל אריח על הלוח וכל מקש במקלדת מקבל אחד מארבעת המצבים.

public enum LetterState {

    ABSENT,   // האות לא נמצאת במילה (אפור)
    PRESENT,  // האות נמצאת במילה אבל במקום אחר (צהוב)

package com.example.hebrewwordle.model;

/**
 * ניחוש אחד: המילה שהוקלדה והמצב של כל אות בה.
 * העצם הזה "קפוא" (immutable): אחרי שנוצר אי אפשר לשנות אותו - כך שורה שכבר נבדקה
 * לעולם לא משתנה בטעות.
 */
public class Guess {

    private final String word;
    private final LetterState[] states;

    public Guess(String word, LetterState[] states) {
        this.word = word;
        this.states = states;
    }

    public String getWord() {
        return word;
    }

    public LetterState getState(int index) {
        return states[index];
    }

    public LetterState[] getStates() {
        return states.clone();   // עותק, כדי שאף אחד בחוץ לא ישנה את המערך הפנימי
    }

    /** ניחוש "מנצח" הוא ניחוש שכל אותיותיו ירוקות. */
    public boolean isAllCorrect() {
        for (LetterState s : states) {
            if (s != LetterState.CORRECT) return false;
        }
        return true;
    }
}

package com.example.hebrewwordle.model;

import java.util.ArrayList;
import java.util.List;

/**
 * חוקי המשחק, ב-Java טהור. המחלקה הזאת לא יודעת שקיים אנדרואיד:
 * אין כאן TextView, אין Button, אין צבעים. בגלל זה אפשר לבדוק אותה ב-JUnit
 * על המחשב, בלי אמולטור.
 */
public class WordleGame {

    public static final int WORD_LENGTH = 5;
    public static final int MAX_GUESSES = 6;

    private final String secret;
    private final List<Guess> guesses = new ArrayList<>();

    public WordleGame(String secret) {
        if (secret == null || secret.length() != WORD_LENGTH) {
            throw new IllegalArgumentException("המילה הסודית חייבת להיות בת " + WORD_LENGTH + " אותיות");
        }
        this.secret = secret;
    }

    /**
     * בודק ניחוש ומוסיף אותו לרשימה.
     * @throws IllegalArgumentException אם אורך המילה שגוי
     * @throws IllegalStateException אם המשחק כבר נגמר
     */
    public Guess submit(String word) {
        if (isOver()) {
            throw new IllegalStateException("המשחק נגמר");
        }
        if (word == null || word.length() != WORD_LENGTH) {
            throw new IllegalArgumentException("הניחוש חייב להיות בן " + WORD_LENGTH + " אותיות");
        }
        Guess guess = new Guess(word, evaluate(secret, word));
        guesses.add(guess);
        return guess;
    }

    /**
     * לב המשחק: משווה ניחוש למילה הסודית ומחזיר מצב לכל אות.
     * שני מעברים: קודם מסמנים ירוקים, ורק אחר כך צהובים - אחרת אות כפולה
     * בניחוש הייתה "גונבת" צהוב שלא מגיע לה.
     */
    public static LetterState[] evaluate(String secret, String word) {
        LetterState[] result = new LetterState[WORD_LENGTH];
        char[] s = normalize(secret).toCharArray();
        char[] g = normalize(word).toCharArray();
        boolean[] usedInSecret = new boolean[WORD_LENGTH];

        // מעבר 1: ירוקים
        for (int i = 0; i < WORD_LENGTH; i++) {
            if (g[i] == s[i]) {
                result[i] = LetterState.CORRECT;
                usedInSecret[i] = true;
            }
        }
        // מעבר 2: צהובים ואפורים
        for (int i = 0; i < WORD_LENGTH; i++) {
            if (result[i] != null) continue;          // כבר ירוק
            result[i] = LetterState.ABSENT;
            for (int j = 0; j < WORD_LENGTH; j++) {
                if (!usedInSecret[j] && g[i] == s[j]) {
                    result[i] = LetterState.PRESENT;
                    usedInSecret[j] = true;         // כל אות במילה הסודית "משלמת" פעם אחת
                    break;
                }
            }
        }
        return result;
    }

    /**
     * אותיות סופיות נחשבות כאות הרגילה: מי שהקליד "מ" במקום "ם" עדיין צודק לגבי האות.
     */
    public static String normalize(String word) {
        return word.replace('ך', 'כ')
                   .replace('ם', 'מ')
                   .replace('ן', 'נ')
                   .replace('ף', 'פ')
                   .replace('ץ', 'צ');
    }

    public boolean isWon() {
        return !guesses.isEmpty() && guesses.get(guesses.size() - 1).isAllCorrect();
    }

    public boolean isLost() {
        return !isWon() && guesses.size() >= MAX_GUESSES;
    }

    public boolean isOver() {
        return isWon() || isLost();
    }

    public String getSecret() {
        return secret;
    }

    public List<Guess> getGuesses() {
        return new ArrayList<>(guesses);
    }

    public int getGuessCount() {
        return guesses.size();
    }
}

מילה סודית: string-array ו-Random

דרך 3: מחלקה פנימית

המאזין של "בדיקה" עושה עבודה אמיתית: בודק, צובע, מעדכן הודעה. מגיע לו שם משלו. מחלקה פנימית היא מחלקה שכתובה בתוך מחלקה אחרת. CheckListener תהיה בתוך MainActivity ותממש את View.OnClickListener. בגלל שהיא בפנים, היא רואה את כל השדות של הפעילות בלי שמעבירים לה אותם.

הודעה עם מספר: getString

ב-strings.xml אפשר להשאיר "חור" בטקסט: %1$d למספר, %1$s לטקסט. getString(R.string.msg_guesses_left, 5) ממלא את החור ומחזיר את ההודעה המוכנה.

איזו שורה עכשיו?

עד עכשיו האותיות נכתבו תמיד לשורה 0. עכשיו השורה היא game.getGuessCount() – מספר הניחושים שכבר נבדקו. אחרי ניחוש אחד היא 1, ולכן ההקלדה עוברת לשורה השנייה.

צביעה: paintTile

לכל מצב של אות יש צורה משלו ב-drawable: tile_correct, tile_present, tile_absent. המתודה paintTile(tile, state) בוחרת את הצורה והצבע לפי ה-LetterState, בעזרת switch.

            for (TextView tile : row) {
                tile.setText("");
                paintTile(tile, LetterState.EMPTY);

        }

        String word = guess.getWord();
        for (int col = 0; col < COLS; col++) {
            tiles[row][col].setText(String.valueOf(word.charAt(col)));
            paintTile(tiles[row][col], guess.getState(col));
        }

        } else if (game.isLost()) {
            txtMessage.setText(getString(R.string.msg_lose, game.getSecret()));
        } else {
            txtMessage.setText(getString(R.string.msg_guesses_left, ROWS - game.getGuessCount()));
        }

        String[] words = getResources().getStringArray(R.array.words);
        String secret = words[new Random().nextInt(words.length)];
        game = new WordleGame(secret);
        current.setLength(0);
        clearBoard();
        txtMessage.setText(R.string.msg_start);
        Log.d(TAG, "משחק חדש. המילה הסודית: " + secret);   // רק לפיתוח - מוחקים לפני הגשה

    private void clearBoard() {
        for (TextView[] row : tiles) {
            for (TextView tile : row) {
                tile.setText("");
                paintTile(tile, LetterState.EMPTY);
            }
        }
        for (Button key : keyByLetter.values()) {
            key.setTag(null);
            key.setBackgroundTintList(ContextCompat.getColorStateList(this, R.color.key_bg));
            key.setTextColor(ContextCompat.getColor(this, R.color.ink));
        }
    }

    /** מציג ניחוש שנבדק בשורה נתונה: אותיות, צבעי אריחים וצבעי מקשים. */
    private void showGuess(int row, Guess guess) {
        String word = guess.getWord();
        for (int col = 0; col < COLS; col++) {
            tiles[row][col].setText(String.valueOf(word.charAt(col)));
            paintTile(tiles[row][col], guess.getState(col));
            paintKey(word.charAt(col), guess.getState(col));
        }
    }

    private void updateMessage() {
        if (game.isWon()) {
            txtMessage.setText(getString(R.string.msg_win, game.getGuessCount()));
        } else if (game.isLost()) {
            txtMessage.setText(getString(R.string.msg_lose, game.getSecret()));
        } else {
            txtMessage.setText(getString(R.string.msg_guesses_left, ROWS - game.getGuessCount()));
        }
    }

    /** אוסף את כל מקשי האותיות למפה, כדי שנוכל לצבוע מקש לפי האות שלו. */
    private void collectKeyboardButtons() {
        keyByLetter.clear();

        for (int r = 0; r < keyboard.getChildCount(); r++) {

            for (int i = 0; i < row.getChildCount(); i++) {
                Button key = (Button) row.getChildAt(i);
                if (key.getId() == View.NO_ID) {          // למחק ולבדיקה יש id, לאותיות אין
                    keyByLetter.put(key.getText().charAt(0), key);
                }
            }
        }
    }

    /** מקש עולה בדרגה בלבד: אפור -> צהוב -> ירוק, אף פעם לא יורד. */
    private void paintKey(char letter, LetterState state) {
        Button key = keyByLetter.get(letter);
        if (key == null) return;
        LetterState old = (LetterState) key.getTag();
        if (old != null && old.ordinal() >= state.ordinal()) return;
        key.setTag(state);

        int color;
        switch (state) {
            case CORRECT: color = R.color.tile_correct; break;
            case PRESENT: color = R.color.tile_present; break;
            default:      color = R.color.tile_absent;  break;
        }
        key.setBackgroundTintList(ContextCompat.getColorStateList(this, color));
        key.setTextColor(ContextCompat.getColor(this, R.color.tile_text_light));
    }

Bundle ו-onSaveInstanceState

רגע לפני שהפעילות נהרסת בגלל סיבוב, אנדרואיד קורא ל-onSaveInstanceState(Bundle). Bundle הוא מילון קטן: שמים בו ערכים פשוטים (מחרוזות, מספרים, רשימות של מחרוזות), כל אחד תחת מפתח. את אותו Bundle אנדרואיד מעביר ל-onCreate של הפעילות החדשה.

מה שומרים? רק את מה שאי אפשר לחשב: המילה הסודית, המילים שניחשו, והאותיות שהוקלדו. את הצבעים לא שומרים – restoreGame שולחת שוב כל ניחוש ל-submit, והצבעים יוצאים אותו דבר.

מתי יש Bundle?

🤔 ומה אם סוגרים את האפליקציה?

            txtMessage.setText(getString(R.string.msg_lose, game.getSecret()));
        } else {
            txtMessage.setText(getString(R.string.msg_guesses_left, ROWS - game.getGuessCount()));
        }
    }

    /** אוסף את כל מקשי האותיות למפה, כדי שנוכל לצבוע מקש לפי האות שלו. */
    private void collectKeyboardButtons() {
        keyByLetter.clear();
        LinearLayout keyboard = findViewById(R.id.keyboard);
        for (int r = 0; r < keyboard.getChildCount(); r++) {
            LinearLayout row = (LinearLayout) keyboard.getChildAt(r);
            for (int i = 0; i < row.getChildCount(); i++) {
                Button key = (Button) row.getChildAt(i);
                if (key.getId() == View.NO_ID) {          // למחק ולבדיקה יש id, לאותיות אין
                    keyByLetter.put(key.getText().charAt(0), key);
                }
            }
        }
    }

    /** מקש עולה בדרגה בלבד: אפור -> צהוב -> ירוק, אף פעם לא יורד. */
    private void paintKey(char letter, LetterState state) {
        Button key = keyByLetter.get(letter);
        if (key == null) return;
        LetterState old = (LetterState) key.getTag();
        if (old != null && old.ordinal() >= state.ordinal()) return;
        key.setTag(state);

        int color;
        switch (state) {
            case CORRECT: color = R.color.tile_correct; break;
            case PRESENT: color = R.color.tile_present; break;
            default:      color = R.color.tile_absent;  break;
        }
        key.setBackgroundTintList(ContextCompat.getColorStateList(this, color));
        key.setTextColor(ContextCompat.getColor(this, R.color.tile_text_light));
    }

    /**
     * נקרא לפני שהפעילות נהרסת בגלל סיבוב מסך.
     * שומרים רק את המינימום שממנו אפשר לשחזר הכול: המילה הסודית, רשימת הניחושים
     * והאותיות שהוקלדו בשורה הנוכחית. את הצבעים לא שומרים - מחשבים אותם מחדש.
     */
    @Override
    protected void onSaveInstanceState(Bundle outState) {
        super.onSaveInstanceState(outState);
        outState.putString(KEY_SECRET, game.getSecret());
        ArrayList<String> words = new ArrayList<>();
        for (Guess g : game.getGuesses()) words.add(g.getWord());
        outState.putStringArrayList(KEY_GUESSES, words);
        outState.putString(KEY_CURRENT, current.toString());
        Log.d(TAG, "onSaveInstanceState - נשמרו " + words.size() + " ניחושים");
    }

    /** בונה מחדש את המשחק מה-Bundle ומצייר את הלוח. */
    private void restoreGame(Bundle state) {
        String secret = state.getString(KEY_SECRET);
        List<String> words = state.getStringArrayList(KEY_GUESSES);
        String typed = state.getString(KEY_CURRENT, "");

        game = new WordleGame(secret);
        clearBoard();
        if (words != null) {
            for (int row = 0; row < words.size(); row++) {
                Guess guess = game.submit(words.get(row));   // הבדיקה מחדש נותנת שוב את הצבעים
                showGuess(row, guess);
            }
        }
        current.setLength(0);
        current.append(typed);
        int row = game.getGuessCount();
        for (int col = 0; col < typed.length() && row < ROWS; col++) {
            tiles[row][col].setText(String.valueOf(typed.charAt(col)));
        }
        updateMessage();
        Log.d(TAG, "restoreGame - שוחזרו " + (words == null ? 0 : words.size()) + " ניחושים");
    }
