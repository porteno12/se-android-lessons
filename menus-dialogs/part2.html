מוסיפים כפתורי תשובה

לכל כפתור נותנים טקסט ומה לעשות כשלוחצים עליו. את התיבה לא צריך לסגור, היא נסגרת לבד.

הוסיפו את השורות המסומנות.

private void showClearDialog() {
    new AlertDialog.Builder(this)
            .setTitle("ניקוי הודעה")
            .setMessage("לנקות את ההודעה שעל המסך?")
            .setPositiveButton("כן", new DialogInterface.OnClickListener() {
                @Override
                public void onClick(DialogInterface dialog, int which) {
                    binding.tvStatus.setText("");
                }
            })
            .setNegativeButton("לא", null)
            .show();
}

DialogInterface.OnClickListener

טעויות נפוצות

לחצו על מה שקורה אצלכם.

לוחצים ושום דבר לא קופץ

השרשרת חייבת להסתיים ב־.show().

התיבה נראית שונה משאר האפליקציה

ייבאתם את android.app.AlertDialog. החליפו ל־androidx.appcompat.app.AlertDialog.

שגיאה באמצע השרשרת

נקודה־פסיק מופיעה רק פעם אחת, בסוף, אחרי .show().

binding.btnClear אדום

ה־id ב־XML חייב להיות בדיוק @+id/btnClear.

לחיצה מחוץ לתיבה סוגרת אותה

ככה זה אמור לעבוד. אם רוצים למנוע את זה, מוסיפים .setCancelable(false) לפני .show().
